# 🧮 Calculator — JavaScript + FastAPI

A modern calculator web application built using **HTML, CSS, JavaScript, and FastAPI**.

The frontend provides an interactive calculator UI, while the FastAPI backend handles the mathematical calculations through a REST API.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Number buttons from 0–9
- 🔹 Decimal number support
- 🧹 Clear button
- ⚠️ Division-by-zero validation
- ⚡ FastAPI REST API
- 🔗 Frontend and backend communication using Fetch API
- 🎨 Modern responsive UI
- ✨ Button hover and click animations
- 📱 Mobile-friendly design

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Fetch API

### Backend

- Python
- FastAPI
- Pydantic
- Uvicorn
